title: スタートアップ用語集｜起業の基本用語を一行で
h1: スタートアップ用語集
desc: スタートアップと起業の基本用語を、一行ずつ解説する用語集。MVP、PMF、LTV、CAC、ユニットエコノミクス、TAM・SAM・SOM、J-KISS、ベスティング、バーンレート、ランウェイ、MOATなど。詳しい頁へのリンク付き。
lead: スタートアップの現場で使われる言葉を、一行ずつ説明する。アルファベット、五十音の順に並べた。詳しく知りたい言葉は、それぞれの頁へ進んでほしい。
---
AARRR | パイレーツメトリクス | ユーザーの行動を、獲得、活性化、継続、紹介、収益の5段階に分解して計測するフレームワーク。 | aarrr
CAC | 顧客獲得コスト | 一人の新規顧客を獲得するためにかかった、広告費や営業コストの総額。 | unit-economics
Competitive market | 競争市場 | 多くの企業が競争し合い、市場シェアが比較的均等に分散している市場。後発でもシェアを獲得できる。 | first-mover-advantage
CPA | | 一人あたりの獲得コスト。高すぎれば、ニーズがあっても事業として成立しない。 | growth
Exit | 出口 | スタートアップの出口。大きくIPOとM&Aの2種類がある。 | exit-ipo-ma
IPO | 新規株式公開 | 証券取引所に株式を公開し、市場から資金調達をしながら独立性を保つ手法。 | exit-ipo-ma
J-KISS | | バリュエーションを決めずに先に資金を受け取る、コンバーティブルエクイティの日本における標準的な無償公開フォーマット。 | j-kiss
Jカーブ | | 初期は赤字を掘り続け、ある地点から急激に成長する、スタートアップの成長曲線。 | what-is-startup
LTV | 顧客生涯価値 | 一人の顧客が取引期間中にもたらしてくれる利益の総額。 | unit-economics
M&A | | 会社や事業を第三者に売却し、その対価を得る手法。 | exit-ipo-ma
MOAT | 競争優位性、堀 | 模倣困難性が高いもの。多くの場合、構築に時間がかかるものが該当する。 | moat
Must have | | 無いと困るサービス。あったらいいね（Nice to have）の反対。 | must-have
MVP | Minimum Viable Product | ユーザーに価値を提供できる、必要最低限のプロダクト。仮説を検証するために作る。 | mvp
Nice to have | | あったらいいね、というサービス。ペインが浅く、お金を払ってもらいにくい。 | must-have
North Star Metric | 北極星指標 | プロダクトがユーザーにもたらしている価値を最も的確に表す、単一の指標。 | aarrr
PGC | Professionally Generated Content | 専門家やプロフェッショナルが作成したコンテンツ。 | ugc-pgc
PMF | プロダクトマーケットフィット | プロダクトが市場に受け入れられている状態。 | pmf
PMI | | M&Aにおける、買収後の統合のこと。 | exit-ipo-ma
SAM | Serviceable Available Market | 事業が実際に提供できる市場規模。自社シェア100パーセント時の売上。 | tam-sam-som
Sean Ellisテスト | | 「このプロダクトが使えなくなったらどう感じるか」を聞き、「とても残念」が40%を超えるかでPMFを測るアンケート。 | pmf
SOM | Serviceable Obtainable Market | 中短期的に、現実的に獲得可能な市場規模。 | tam-sam-som
TAM | Total Addressable Market | 事業が提供できる製品やサービスに対する、市場全体の需要。理論上の最大売上高。 | tam-sam-som
UGC | User Generated Content、ユーザー生成コンテンツ | ユーザーが作成したコンテンツ。 | ugc-pgc
Why now | | なぜ今この事業をやるのか、という問い。投資家が使う3つのWhyのうち、最も重視される。 | pitch-tips
Winner takes all | 勝者総取り | ほんの一握りの企業が圧倒的な市場シェアを獲得する市場。ネットワーク効果が働くビジネスに多い。 | first-mover-advantage
アーンアウト | | M&Aで、将来の業績達成を条件に対価の一部が支払われる取り決め。 | exit-ipo-ma
アクセラレーションプログラム | アクセラレーター | 短期間で事業を立ち上げ、成長させるためのプログラム。メンターがつく無料のハンズオン支援。 | accelerator
エスクロー | | 運営が取引の間に入り、代金を仲介する仕組み。 | take-rate
エンジェルラウンド | | 創業直後、アイデアと人に対して投資される資金調達の段階。 | funding-rounds
オンボーディング | | ユーザーが登録してから、最初に価値を実感するまでの体験。 | unit-economics
カスタマーサクセス | | 問い合わせが来る前に、ユーザーが成果を出せるよう能動的に働きかける機能。 | unit-economics
希薄化 | | 資金調達で新しい株式が発行され、既存株主の持株比率が下がること。 | capital-policy
キャッシュアウト | | 現金が出ていくこと全般。家賃や給与の支払いも含む。資金が尽きることを指す言葉ではない。 | burn-rate-runway
クリフ | | ベスティングの最初に置く、権利が一切確定しない期間。一般的には1年。 | founder-equity
黒字倒産 | | 帳簿上は黒字なのに、支払いの期日に現金が足りず倒産すること。 | burn-rate-runway
後発優位性 | セカンドムーバーアドバンテージ | 後発者だけが持つ利点。文化浸透の苦労が不要、先行者の最適解を使える、など。 | first-mover-advantage
コンバーティブルエクイティ | | バリュエーションを決めず、将来の資金調達ラウンドで株式に転換される権利を発行して、先に資金を受け取る仕組み。 | j-kiss
サンクコスト | | 既に支払ってしまい、取り戻せない費用。初期費用は、解約しづらくなる効果を持つ。 | pricing
シードラウンド | | プロダクトの初期検証段階の資金調達。 | funding-rounds
資本政策表 | キャップテーブル | 誰が何株持っていて、それが全体の何パーセントに相当するかを一覧にした表。 | capital-policy
シリーズA | | 事業モデルが確認され、成長を加速させる段階の資金調達。 | funding-rounds
ジョブ理論 | | 人は製品が欲しいのではなく、片付けたい用事のために製品を雇っている、という捉え方。 | must-have
スイッチングコスト | | サービス間を移行する際にかかる、金銭的、時間的、心理的コスト。 | switching-cost
スタートアップ | | 先進的なテクノロジーを用いて事業を立ち上げ、資金調達を繰り返して短期的な急成長を果たし、最終的にIPOや事業売却を目指す企業。 | what-is-startup
ストックオプション | | あらかじめ決められた価格で、将来株式を取得できる権利。 | founder-equity
スモールビジネス | | 安定した収入を目指し、持続可能な規模で運営される事業。急成長やIPOを必ずしも目指さない。 | what-is-startup
セカンダリーマーケット | 二次流通 | 個人や企業の間で物品を売買する、二次流通サービス。 | business-models
先行優位性 | ファーストムーバーアドバンテージ | 先行者、あるいはそれに近い立場の者だけが手に入れられる優位性。 | first-mover-advantage
ダウンラウンド | | 前回より低い評価額で資金調達をせざるを得なくなること。 | investor-relations
テイクレート | | プラットフォームサービスにおける、取引手数料の割合。 | take-rate
デュアルトラック | | IPOとM&Aの両方を、出口として並行して見据える経営の考え方。 | exit-ipo-ma
転換 | | マッチングサービスで、買い手と売り手が時に立場を入れ替えること。 | marketplace
トラクション | | 事業の成果を示す実績。具体的な数字を添えて示す。 | pitch-deck
ネットワーク効果 | | サービスの価値がユーザー数に依存していること。多くのユーザーが集まるほど、全員にとって価値が高まる。 | first-mover-advantage
バーンレート | | 会社が1ヶ月あたりに消費する資金の額。 | burn-rate-runway
バイアウト | | 事業を買い取ること。売った起業家の側は「バイアウトされた」と表現するのが正しい。 | exit-ipo-ma
バリュエーションキャップ | | J-KISSで、転換価額を計算する際の評価額の上限。 | j-kiss
ハンズオフ | 直接取引型 | 売り手と買い手が直接取引を行い、運営は個々の取引に関与しない型。 | take-rate
ハンズオン | 運営仲介型 | 運営が取引の間に入る型。真贋確認や物流の手間がかかるため、手数料は高めに設定する。 | take-rate
ビジネスドライバー | | その事業が何によって動いているか、という要因。 | marketplace
ピボット | | 事業の方向転換。PMFの指標が届かないときに検討する。 | pmf
プロダクトアウト | | 自社のアセットを起点に事業を考えるアプローチ。 | market-in-product-out
ベスティング | | 時間の経過に応じて、株式やストックオプションの権利が確定していく仕組み。 | founder-equity
マーケットイン | | ユーザーのニーズを起点に事業を考えるアプローチ。 | market-in-product-out
無消費 | | 既存の製品やサービスを使わずに、我慢している状態。 | must-have
優先株式 | | 清算やM&Aの際に、普通株式の株主より先に分配を受け取れる優先分配権が付いた株式。 | j-kiss
ユニットエコノミクス | | 顧客一人あたりの採算。LTVをCACで割って求め、3倍以上が健全とされる。 | unit-economics
ランウェイ | | 手元資金が、今のバーンレートのペースで尽きるまでの残り期間。 | burn-rate-runway
ランドグラブ戦略 | 陣取り合戦 | 後発が同じものを作ってくる前提で、いち早く導入してもらい、陣地を広げていく戦い方。 | switching-cost
リテンションカーブ | | ユーザーの継続利用率を、時間軸でグラフにしたもの。 | pmf
ロックアップ | | M&Aで、買収後の一定期間、経営陣が会社に残ることを求める条項。 | exit-ipo-ma
