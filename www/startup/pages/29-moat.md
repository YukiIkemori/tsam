## 正しい競争優位性とは

正しい競争優位性とは、模倣困難性が高いものである。多くの場合、構築に時間がかかるものが該当する。資本力などで短時間で取得できるものは該当しない。競争優位性が無いと、事業は後々生き残ることができない。

## 競争優位性に該当しない例

| 該当しないもの | 理由 |
|---|---|
| 便利な機能 | 仕様による差異は競争優位性ではない。コモディティ化していくと、機能面での差別化はほとんど期待できない |
| 斬新な手法 | 本当に素晴らしいならば、すぐにデファクトスタンダードになる。誰もが真似をして、差ではなくなる |
| 圧倒的クオリティ、お洒落なデザイン、使いやすい機能 | 質や好みは人それぞれである |
| くじけぬ心、仲の良いチーム | 精神論はナンセンスである |

「この業界に長くいるので、自分にしか分からない」というのも、多くの場合は優位性にならない。同じ業界で同じ経験を持つ人なら、同じことができるからである。自分に5日でできることは、世の中の誰かにも5日でできる。

## 競争優位性に該当する13の例

| 例 | 時間がかかる理由 |
|---|---|
| 1. コミュニティ | 長い時間をかけて運営し、エンゲージメントを上げなければ手に入らない |
| 2. データベース | 何度も取引を発生させ、データを貯めなければ構築できない |
| 3. 信用の可視化 | ある程度の取引実績がなければ、レビューや評価は貯まらない |
| 4. コンテンツの独占確保 | 一気にまとめて落とすことはできない |
| 5. サポートノウハウ | 場数を踏んで貯めるしかない |
| 6. 顧客への独自のチャネル | 長年の活動によってのみネットワークは築ける |
| 7. アセットへの導線 | 持っているか、導線があるかがすべてである |
| 8. スイッチングコスト | いずれの方法も時間が必要とされる |
| 9. ネットワーク効果 | ファーストペンギンの立ち位置を取れるかが重要になる |
| 10. 特定セグメントへのエンゲージメント | 長い時間をかけて対象と交流しなければならない |
| 11. ブランディング | 長年のサポート実績や結果が必要になる |
| 12. アライアンス | 適切な関係値が必要になる |
| 13. 知的財産権 | 時間の経過を必要としない、例外的な競争優位性 |

### 1. コミュニティ

LTV、スイッチングコスト、バイラル係数などの各種数値が向上する。互助効果によって管理育成コストが軽減され、価格優位性も生まれる。

### 2. データベース

データベースの有無がコンバージョンの要素になる場合がある。

### 3. 信用の可視化

CtoCサービス全般において、コンバージョンには信用の可視化が必要であり、多くの場合レビューや評価システムで解決している。

### 4. コンテンツの独占確保

コンテンツホルダーが少数で希少な場合、事前にリーチし、独占契約などで囲い込んでしまうと、後発は参入したくてもできない。ステルスで運営するのが肝である。

### 5. サポートノウハウ

ユーザー層が若いときやリテラシーが低いときは、サポートコストが多大に発生する。円滑に解決できるかが、顧客満足度とリテンションレートに影響する。

### 6. 顧客への独自のチャネル

コミュニティやメディアなどで、対象セグメントへのチャネルを確保しているか否か。導線があるならば、最初からコンテンツ確保の目処がつく。

### 7. アセットへの導線

アセットビジネスを行う場合、システム側での優劣には意味がない。そのアセットを保有しているか否か、導線があるか否かがすべてである。目処が立っていないのならば、そのビジネスは行うべきではない。アセットもパワーのあるアセットが必要で、数より質である。

### 8. スイッチングコスト

ユーザーのスイッチングコストが高い環境を作り出せたのならば、圧倒的な優位性に繋がる。作り方は[スイッチングコストの頁](/startup/switching-cost)に書いた。

### 9. ネットワーク効果

プラットフォームサービスほどネットワーク効果が働きやすい。バイラル係数も上がるので、ユーザー獲得という意味でも重要である。

### 10. 特定セグメントへのエンゲージメント

コンサバティブな業界ほど、ステークホルダーとのエンゲージメントが高いかどうかで、市場に参入できるか、リプレイスできるかが決まる。

### 11. ブランディング

安心感や信頼感をブランドイメージとして持たせると、些細な差別化や価格優位性を乗り越えることができる。思想を浸透共有させる必要がある。

### 12. アライアンス

シナジーが効く企業とのアライアンスを結ぶことで、サービスの拡充や信頼性の担保に繋がる。トップダウンで影響力が強い業界団体や行政ならば、より効果的である。消費者向けにちまちま広告費を使うのではなく、企業や行政とのアライアンスによるニュースで露出を図り、社会的なプレゼンスを上げることで、コストパフォーマンス良く知名度と信用を勝ち取る戦略にもなる。

### 13. 知的財産権

特許によって他社が容易には導入できない、つまり模倣困難性が高い状態を作れる。

## 知財戦略。初期は特許より商標

知的財産権と一口に言っても、スタートアップの初期フェーズで優先すべきは特許ではなく商標である。特許は技術的な新規性の審査に時間がかかり、取得コストも高い。一方、商標はサービス名やロゴといったブランドそのものを守るものであり、初期投資に対する防御効果が大きい。

商標には**先願主義**が適用される。先に使っていたかどうかではなく、先に出願したかどうかで権利が決まる。つまり、自分たちが名付けたサービス名であっても、登録を怠っている間に他社に先取りされるリスクが常にある。サービスが世に知られ、認知が育つほど、後から名前を変えるリブランディングのコストは膨らんでいく。まだ無名のうちに動くほうが、圧倒的に安く済む。

商標登録は、単に権利を守るためだけの手続きではない。登録していること自体が、対外的な信頼材料、つまり資金調達の場面での説得材料になる。きちんと権利関係を整理している会社だという印象は、投資家からのデューデリジェンスでも評価される。

## ブランディングは細部に宿る

ブランディングは競争優位性の一つだが、その多くは思想やストーリーではなく、目に見える細部の積み重ねで決まる。

どれだけ良い想いを語っても、サイトのデザインがテンプレートのままだったり、独自ドメインを取っていなかったり、Faviconすら設定されていなかったりすると、その想いは伝わる前に台無しになる。これはオンラインに限らない。届いた梱包が無地の段ボールなのか、世界観に沿ったデザインが施されているのかで、受け取る側の印象は大きく変わる。

もう一つの手法は、意図的に不便さを設計に組み込むことである。いつでも買えるものはそれゆえに後回しにされるが、購入できる時間や数量を制限すると、その不自由さを乗り越えてでも欲しいという欲求が生まれる。

## 事業そのもので優位性を作れないとき

事業の内容で差がつけにくくても、戦略で優位性を作ることはできる。

- **ビジネスモデルで作る。**ネットワーク効果が働くモデルなら、技術で劣っていても、先に始めた側に顧客が集まる
- **地域で作る。**物理的な距離に制限がある事業なら、他社がある地域を押さえても、自社は別の地域を押さえればそこでは勝てる
- **陣取りで作る。**いち早く導入してもらい、スイッチングコストを高めて守る

ピッチで競争優位性を伝えるときは、無理に大きく見せない。巨大企業が自社で手がけている領域で「技術で勝っている」と言っても、信憑性に欠ける。

## よくある質問

?? 競争優位性とは何か。
模倣困難性が高いもののことである。多くの場合、構築に時間がかかるものが該当し、資本力などで短時間に取得できるものは該当しない。

?? MOATとは何か。
堀のことで、スタートアップでは競争優位性を指す言葉として使われる。他社が簡単に攻め込めない状態を作るものを言う。

?? 機能の多さや使いやすさは競争優位性になるか。
ならない。仕様による差異は、コモディティ化していくと差別化にならない。質や好みは人それぞれである。

?? 特許と商標はどちらを先に取るべきか。
初期フェーズでは商標である。特許は審査に時間がかかり、取得コストも高い。商標は先願主義なので、無名のうちに出願しておく。

?? 競争優位性と差別化は何が違うのか。
差別化は他社との違いを作ることだが、真似できる違いは競争優位性にならない。競争優位性は、他社が真似しようとしても時間がかかるものを指す。
