# お問い合わせフォームの送信の仕組み（設置の手順）

**【未検証】まだ設置していない。**設置して一通送ってみるまでは、サイトのフォームは「メールアプリを開く」動きのまま。

## しくみ

新しいサイトは置いてあるだけのファイルなので、自分ではメールを送れない。そこで Google Apps Script（Google アカウントがあれば無料で使える小さな受け口）を一つ作り、
フォームはそこへ送る。受け口が ikemori@tsam.co.jp へメールを出す。

```
フォーム（tsam.co.jp） → Google Apps Script（forms/contact.gs） → ikemori@tsam.co.jp
```

- 届くメールの返信先は書いた人のアドレスなので、そのまま返信できる
- 送り主（From）は、受け口を作った Google アカウントのアドレスになる
- 1日に送れる数に上限がある（無料の Google アカウントで 100 通ほど）。お問い合わせの数なら足りる
- さくらのメールの設定には何も触れない

## 手順（池森さんの Google アカウントで。10分ほど）

1. https://script.google.com/ を開き、「新しいプロジェクト」。名前は「tsam お問い合わせ」など
2. 最初から入っているコードを全部消して、このリポジトリの `forms/contact.gs` の中身を貼る。保存
   - 歯車（プロジェクトの設定）で「appsscript.json マニフェスト ファイルをエディタで表示する」に印を付け、
     出てきた `appsscript.json` の中身を、このリポジトリの `forms/appsscript.json` に置き換える。
     これで、この受け口が求める権限は**「メールを送る」だけ**になる（スプレッドシートなどには触れない）
3. 右上の「デプロイ」→「新しいデプロイ」→ 種類は「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
4. 「デプロイ」を押す。初回は「このアプリがメールを送ること」の許可を求められるので、許可する
5. 出てきた「ウェブアプリの URL」（`https://script.google.com/macros/s/…/exec`）を控える
6. その URL を `www/src/data/site.ts` の `contactEndpoint` に入れて、サイトを出し直す（ここは Claude がやる。URL を伝えてもらえればよい）
7. サイトのフォームから一通送って、ikemori@tsam.co.jp に届くこと、返信が書いた人に届くことを確かめる

## 知っておくこと

- この URL は秘密ではない（サイトの中に見える）。受け口は「決まった宛先にメールを出す」ことしかしないので、知られても宛先は変えられない
- 機械に Google の送信枠を使い切られないための関門は四つ（2026-11-26、Dots の指摘で足した。`contact.gs` の頭に詳しく書いてある）
  1. **札**。フォームは書き始めたときに受け口から札を一枚もらい、送信のときに添える。札が無い・署名が合わない・もらって4秒たっていない・
     2時間を過ぎた・一度使った、のどれかなら送らない。フォームを通らずに送信だけ投げる機械はここで止まる
  2. 人に見えない欄（埋まっていたら捨てる）
  3. **1時間に10通、1日に40通まで**。数は消えない場所に持ち、数えるあいだは鍵をかける
  4. Google の送信枠の残りが20通を切ったら送らない
  札は「頁を開いて数秒待つ」機械なら通れる。それでも 3 と 4 があるので、枠を使い切られることはない。
  もっと固くしたくなったら、Cloudflare Turnstile のような外の検証を足す（鍵の発行が要る。いまは入れていない）
- 控え（スプレッドシート）は残さない作りにした。メールが届かなかったときの控えが要るなら、権限を足す話になるので相談
- 筋道の確認は `node forms/contact.test.cjs`（Google の部品を真似た箱の中で13件）。**本物の Apps Script で確かめたことにはならない**
- コードを直したら、Apps Script の画面で貼り直して「新しいバージョン」でデプロイし直す。URL は変わらない
- やめるときは、Apps Script の「デプロイを管理」でアーカイブし、`contactEndpoint` を空に戻す（メールアプリを開く動きに戻る）
- プライバシーポリシーの文面は旧サイトのまま。フォームの内容が Google を通ることを書き足すかどうかは、オーナーの判断
