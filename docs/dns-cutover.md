### 分かっていること

- **MX が tsam.co.jp そのものを指している。**サイトの A を先に変えると、メールも一緒に Firebase へ行って届かなくなる。だから B が先
- **メールの流れ**：tsam.co.jp 宛て → さくらVPS で受ける → Gmail へ転送。受信は MX さえ正しければ、サイトの切り替えの影響を受けない
- **Gmail の送信**（2026-11-26、Dots が画面で確認）：一つ目の Gmail は SMTP が `tsam.jp`・465番・SSL。`tsam.co.jp` ではないので、
  サイトの A を変えても送信は止まらない。もう一つの Gmail は未確認（上のお願い 3）
- **SPF** は、さくらVPS の IP を直に書いたもの。メールはこれからも同じ IP から出るので変えない。新しいサイト（Firebase）はメールを送らない。
  お問い合わせフォームの通知は Google のアカウントから Gmail のアドレスで出るので、tsam.co.jp の SPF には関わらない
- **blog・101・investors・test・wp は本体への相乗り**（CNAME）。本体の A を変えると一緒に動く。
  いまのブログは記事を `tsam.co.jp/wp-json/…` から読んでいるので、ブログだけさくらに残すことはできない。**公式とブログは同時に切り替える**
- **消すと決まったもの**：101（オーナー 2026-11-25）、investors・test・wp（オーナー 2026-11-26）
- **消すと決まったものの扱い**：四つのサブドメインは、下の証明書の事情で、切り替えの日には消さずに行き先だけ付け替える。
